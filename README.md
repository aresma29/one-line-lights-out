## The entry

A single status update from the moment the lights go out: a laptop lid
snaps shut mid-sentence, the room goes dark, and the narrator is left
alone with an apology that never got sent. The humour sits in the gap
between the grand gesture of "going dark" and the small, awkward truth
behind it — nobody left, nobody typed anything, and the unsent message
is doing all the talking.

> Status: going dark. He closed the lid mid-sentence, so I'll just sit here in the dark, holding his unsent apology.

## How it runs

`main.py` prints the contents of `entry.txt` exactly as stored, using
only the Python standard library. Run it with `python3 main.py` and it
exits 0 after writing the entry line to standard output.
